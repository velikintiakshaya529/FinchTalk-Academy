# Finchtalk Academy Website

## 📌 Project Overview

Finchtalk Academy Website is a responsive educational institute landing page developed using HTML5 and CSS3.
The website showcases training programs, trending courses, mentor information, testimonials, and contact details for learners who want to build a career in IT.

This project demonstrates frontend web development skills, including layout structuring, responsive design, and modern UI sections.

## 🚀 Features

- Responsive website layout
- Navigation bar with contact information
- Hero section with academy introduction
- Trending IT courses display
- Founder message and mentor section
-  Key features of the academy
- Testimonials section
- Footer with course categories and company information
- Social media icons and contact details

## 🛠 Technologies Used

- HTML5
- CSS3
- Responsive layout design
- SVG images and icons
